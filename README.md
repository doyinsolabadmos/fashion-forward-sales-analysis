# Fashion-Forward-Sales-Analysis
An Excel data analysis project exploring customer purchasing behavior, product demand and sales performance using data cleaning, PivotTables, PivotCharts and an interactive dashboard.

### Project Overview
Fashion Forward is a data analytics project focused on analysing the sales performance and customer purchasing behaviour of a Nigerian online fashion retail business.
The project involved examining transactional data to identify purchasing patterns, evaluate product performance and understand sales distribution across different categories, locations and sales channels. Microsoft Excel was used to clean, analyse and visualise the data, with the results presented through an interactive dashboard.

### Dataset Description
The project used a training dataset representing transactions from a Nigerian online fashion retail business.The dataset contained information about products, customer transactions, geographical locations, order types and payment methods.
Initial records: 669
Duplicate records removed: 9
Final records: 660
The original dataset is not included in this repository.

### Tools Used
Microsoft Excel 2019: Used for data cleaning, data preparation, analysis, PivotTables, PivotCharts, data visualisation and interactive dashboard development (https://www.microsoft.com)

### Data Cleaning and Preparation
The dataset was examined and prepared before analysis, The process involved:
- Identifying and removing duplicate records.
- Checking data consistency.
- Standardising relevant entries.
- Preparing the dataset for analysis.
  
### Analysis Performed
- The analysis covered:
- Sales performance.
- Product and category performance.
- Customer purchasing behaviour.
- Geographical sales distribution.
- Monthly sales trends.
- Sales channel performance.

### Dashboard
An interactive Excel dashboard was developed to present the findings. It incorporated key performance indicators, charts and interactive slicers for exploring the data by selected categories.

### Key Findings
The project examined patterns in product demand, customer purchasing behaviour, geographical sales distribution and overall business performance. The specific numerical findings and business insights are presented in the accompanying Excel workbook and project report
